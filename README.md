# sd-toolkit

A suite of tools to assist in dataset preparation, LoRA training and LoRA management. Made for personal use.



## Questions Nobody Asked

This is a project intended primarily for personal use, so it isn't optimized for
other users' convenience. If you PR changes I will consider merging them, but
I will probably ignore feature requests.

This project is released without a license for a similar reason. I don't care
about others' use of it (unless you go out of your way to displease me with it,
I guess). If you really want it to be open-source-licensed, ask me. Same goes
if you believe I might be legally obligated to license it in a certain way.
